# Plugin Roadmap

## portal-core

Responsibilities:

- Application catalog
- User/team model
- Entitlement management
- External resource binding
- Audit trail

## plugin-newapi

Responsibilities:

- OIDC integration
- Model catalog
- Usage dashboard
- Quota mapping
- Token provisioning

## plugin-multica

Responsibilities:

- Workspace provisioning
- Member synchronization
- Agent runtime links
- Task dashboard

## plugin-agent-memory

Responsibilities:

- TencentDB Agent Memory configuration
- Agent/user/team namespace mapping
- Memory policy management

## plugin-wanta

Responsibilities:

- Desktop download
- Deep link integration
- Agent workspace launch

## Development Order

Phase 1:

- portal-core
- identity model
- app launcher

Phase 2:

- New API integration
- Multica integration

Phase 3:

- Agent Memory integration
- Wanta runtime integration
